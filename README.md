# wyattzani.github.io

Portfolio site for Wyatt Zani, electrical engineering student at Northeastern University.
Live at https://wyattzani.github.io

## Editing

- **Projects:** `_data/projects.yml` — one entry per project. Add photos to `assets/img/` and set `image:`.
- **Name, tagline, contact links, résumé:** `_config.yml`
- **About section:** `_includes/about.html`
- **Styles:** `assets/css/site.css`

Every commit to `main` rebuilds the site. If a change doesn't appear, check the Actions tab for a failed build.

Built with Jekyll. Originally based on the Particle theme by Nathan Randecker (MIT license, see LICENSE.txt).
